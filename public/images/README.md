# Sandwich & Brand Images

Drop the following files into this folder (exact filenames matter):

| File name        | What it is                         |
| ---------------- | ---------------------------------- |
| `roast-beef.jpg` | Pastrami / roast-beef sub photo    |
| `turkey.jpg`     | Turkey breast sub photo            |
| `bacon.jpg`      | Bacon sub photo                    |
| `chicken.jpg`    | Grilled chicken sub photo (pasted) |
| `logo.png`       | Orange Chomp Sandwich square logo  |

Recommended:

- Sandwiches: 1280×800 (4:3 or 16:10), JPG, ≤ 250 KB
- Logo: 512×512 PNG with transparent or orange background

After dropping the files, no code changes are needed — references are
already wired up in `lib/menu.ts` and `components/Logo.tsx`.
