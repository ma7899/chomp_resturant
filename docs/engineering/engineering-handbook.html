Fast Path

# first boot
npm ci && npm run db:generate && npm run db:push && npm run db:seed && npm run dev

# regular boot
npm run dev

برای تغییرات امن تیمی از db:migrate استفاده کنید؛ db:push برای نمونه‌سازی و محیط غیر Production مناسب است.

12-14) Styling System, State Management, Routing

12-14) سیستم استایل، مدیریت استیت، مسیریابی

Tailwind-driven design system with RTL-friendly typography and responsive layout. Zustand is used for cart/auth modal and legacy admin state. App Router provides nested routes and dynamic route segments.

سیستم طراحی مبتنی بر Tailwind با تایپوگرافی سازگار با RTL و ساختار واکنش‌گرا. Zustand برای سبد/مودال auth و بخشی از استیت قدیمی ادمین استفاده می‌شود. App Router مسیرهای تو در تو و داینامیک را مدیریت می‌کند.

Database Migration Roadmap (When Needed)

نقشه راه مهاجرت دیتابیس (در صورت نیاز)

Safe 6-Step Migration Path

مسیر امن 6 مرحله‌ای مهاجرت

  1. Add schema changes in Prisma with backward compatibility.
  2. Create migration and apply in staging.
  3. Deploy app code that can read old/new shapes.
  4. Run data backfill script if required.
  5. Switch writes fully to new schema.
  6. Remove legacy fields/tables in a later release.
  1. تغییر schema را با سازگاری عقب‌رو در Prisma اضافه کنید.
  2. migration بسازید و روی staging اعمال کنید.
  3. کدی deploy کنید که هم فرم قدیم هم جدید را بخواند.
  4. در صورت نیاز backfill اجرا کنید.
  5. نوشتن داده را کامل به schema جدید منتقل کنید.
  6. فیلد/جدول Legacy را در release بعدی حذف کنید.

Operational Migration Matrix

ماتریس عملیاتی مهاجرت

PhaseActionGuardrailRollback
ExpandAdd nullable columns / new tablesNo breaking constraintsRevert code only
MigrateBackfill and dual-readValidation and row countsDisable new readers
SwitchFlip writes to new modelCanary + metricsToggle write path back
ContractDrop old columns/tablesPost-release stability windowRestore from backup snapshot
Never run destructive schema drops in the same release as first-write switch unless you have verified backups and rollback drills.
حذف تخریبی schema را همزمان با اولین سوئیچ write اجرا نکنید مگر اینکه بکاپ معتبر و تمرین rollback داشته باشید.
